# Egyptian Magician — Transparent Animation Studies

Each PNG is an eight-frame 4 × 2 sheet with a genuinely transparent background.

| Action | Sheet | Motion intent |
|---|---|---|
| Attack | `magician_attack_sheet.png` | Planted cast, expanding lunar-water detonation, projection, and settle. |
| Idle | `magician_idle_sheet.png` | Calm breathing loop with pulsing orb and delayed robe/ribbon drift. |
| Block | `magician_block_sheet.png` | Compact crescent ward, ripple impact, compression, and dispersal. |
| Take damage | `magician_take_damage_sheet.png` | Upper-body contact, staff-supported stagger, orb flicker, and recovery. |

See `animations.json` for suggested playback timing and `../ANIMATION_PIPELINE.md` for the shared alpha and layout contract.
