# Egyptian Warrior — Transparent Animation Studies

Each PNG is an eight-frame 4 × 2 sheet with a genuinely transparent background.

| Action | Sheet | Motion intent |
|---|---|---|
| Attack | `warrior_attack_sheet.png` | Heavy shield-led step, committed khopesh strike, hit-stop, and settle. |
| Idle | `warrior_idle_sheet.png` | Regal breathing loop with subtle shield, braid, and cloth movement. |
| Block | `warrior_block_sheet.png` | Shield-dominant brace, sunburst impact, compression, and recovery. |
| Take damage | `warrior_take_damage_sheet.png` | Exposed-shoulder contact, protected stagger, and balance recovery. |

See `animations.json` for suggested playback timing and `../ANIMATION_PIPELINE.md` for the shared alpha and layout contract.
