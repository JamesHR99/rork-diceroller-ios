# Egyptian Rogue — Transparent Animation Studies

Each PNG is an eight-frame 4 × 2 sheet with a genuinely transparent background.

| Action | Sheet | Motion intent |
|---|---|---|
| Attack | `rogue_attack_sheet.png` | Fast overlapping dual-khopesh cuts with strong smear and a low recovery. |
| Idle | `rogue_idle_sheet.png` | Breathing, alert weight shifts, and delayed braid/cloth motion. |
| Block | `rogue_block_sheet.png` | Low brace, crossed-blade impact, recoil, and guarded recovery. |
| Take damage | `rogue_take_damage_sheet.png` | Fast contact, sharp stagger, balance catch, and recovery. |

See `animations.json` for suggested playback timing and `../ANIMATION_PIPELINE.md` for the shared alpha and layout contract.
